## 3. Кэш-резерв под просадки — 12–16 тыс. €

- Максимум по плану траншей: 2 700 + 5 400 + 8 100 = 16 200 €. Держать 12–16 тыс.,

## 5. Дом через ~7 лет — glide path

Sequence risk: обвал за 1–2 года до покупки срежет первоначальный взнос без
времени на восстановление. Правило: **за 3–4 года до покупки** начать переводить
будущий взнос из акций в XEON/короткие EUR-облигации: T−4 ~60 % акций →
T−3 ~40 % → T−2 ~20 % → T−1 0 %. Основной пенсионный портфель не трогать.
Когда станет известна сумма дома — смоделируем изъятие в прогнозе отдельно.
