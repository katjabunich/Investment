# Инвестиционная система

Личный набор инструментов пассивного инвестора (Interactive Brokers, ~200k EUR,
buy & hold + докупки на просадках). Всё считается на исторических данных,
а не «под фиксированный процент».

## Из чего состоит

| Инструмент | Что делает |
|---|---|
| `tools/forecast.py` | Прогноз капитала методом Монте-Карло: 10 000 сценариев на исторических доходностях (блочный бутстрэп месячных данных), перцентили по годам, вероятность достичь цели, сравнение сценариев взносов |
| `tools/cashflow.py` | Рекомендует размер месячного взноса из ваших доходов/расходов: сначала подушка безопасности и резервы под крупные траты, потом инвестиции |
| `tools/monitor.py` | Следит за просадкой рынка от максимума и подсказывает, когда докупить транш (−10 % / −20 % / −30 %), ведёт журнал докупок, показывает исторические просадки для перспективы |
| `tools/gurus.py` | Скачивает квартальные отчёты 13F известных инвесторов (Баффет, Далио, Акман, Бьюрри и др.) из SEC EDGAR и показывает, что они купили/продали |
| `tools/fetch_data.py` | Загружает исторические котировки (Stooq, опционально yfinance) в `data/` — их используют forecast и monitor |
| `docs/strategy.md` | Исследование стратегии под ваш профиль: UCITS-фонды, lump sum vs DCA, честный разбор «докупок на дне», клонирование 13F, крипта 1–3 %, итоговая структура портфеля |

## Быстрый старт (локально, на вашем компьютере)

**Просто хотите увидеть картинку?** Одна команда — и откроется наглядный
отчёт (графики, цифры, план докупок) прямо в браузере:

```bash
python3 start.py
```

Ниже — продвинутый вариант с отдельными инструментами.

Из облачных сессий Claude доступ к финансовым API заблокирован, поэтому
данные скачиваются локально — это одна команда.

```bash
git clone <этот репозиторий> && cd Investment
pip install -r requirements.txt

# 1. Скачать исторические данные (Stooq, бесплатно, без ключей)
python3 tools/fetch_data.py

# 2. Прогноз капитала (работает и без шага 1 — на встроенном резервном датасете)
python3 tools/forecast.py --years 20 --goal 1000000
python3 tools/forecast.py --compare 500,1000,2000   # сценарии взносов

# 3. Сколько инвестировать в месяц
python3 tools/cashflow.py                            # из config/cashflow.yaml
python3 tools/cashflow.py --income 5000 --expenses 3000   # быстрая прикидка

# 4. Просадка сейчас: пора ли докупать?
python3 tools/monitor.py
python3 tools/monitor.py --log-purchase 2000         # записать сделанную докупку

# 5. Что купили/продали известные инвесторы за квартал
python3 tools/gurus.py fetch --all
python3 tools/gurus.py diff --investor "Berkshire"
```

## Что заполнить под себя

1. **`config/portfolio.yaml`** — уже заполнен: SXR8 50 % / EXUS 27,8 % /
   EIMI 11,1 % / EQQB 11,1 %, портфель 187 480 €, взнос 2 700 €/мес.
   Меняйте здесь суммы и веса, когда что-то изменится.
2. **`config/cashflow.yaml`** — доходы, расходы, подушка, крупные планы
   (пока плейсхолдеры — впишите свои цифры).
3. **`config/monitor.yaml`** — размер резерва под просадки и пороги траншей.
4. **`config/gurus.yaml`** — каких инвесторов отслеживать (CIK уже проставлены).

## Рабочий ритуал

- **Раз в месяц** (день взноса): `cashflow.py` → скорректировать взнос →
  `monitor.py` → если сигнал просадки, докупить транш и записать в журнал.
- **Раз в квартал** (середина февраля/мая/августа/ноября — через ~45 дней после
  конца квартала выходят 13F): `gurus.py fetch --all && gurus.py diff ...`.
- **Раз в год**: `fetch_data.py --force` → `forecast.py` — обновить прогноз;
  ребалансировка портфеля к целевым весам (см. `docs/strategy.md`, раздел 8).

## Рекомендованная структура портфеля (из docs/strategy.md)

- **Ядро 60–70 %** — мировой аккумулирующий UCITS ETF (ирландский домицилий).
- **Облигации / денежный рынок EUR 25–35 %** — стабилизатор и источник кэша.
- **Сателлит «гуру» 0–5 %** — отдельные акции по идеям из 13F, если интересно.
- **Крипта 1–3 %** — только BTC/ETH через физические ETP прямо на IBKR.
- **Резерв под просадки 5–10 %** (пересекается с денежной частью) — транши
  на −10/−20/−30 %.

Подробная аргументация с исследованиями и источниками — в `docs/strategy.md`.

## Честные оговорки

- Это инструменты для размышления, **не индивидуальная инвестиционная
  рекомендация**. Прошлые доходности не гарантируют будущих.
- Монте-Карло на исторических данных честнее «фиксированных 7 %», но и он
  не знает будущего: реальный XXI век пока скромнее XX (см. strategy.md, §6).
- Налоги зависят от страны налогового резидентства — их здесь нет,
  уточняйте локально.
- «Докупка на дне» — в первую очередь дисциплина, а не источник большой
  дополнительной доходности (см. strategy.md, §3).
